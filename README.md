Aerlume Site

Flight, hotel and bus search website for Aerlume, built on an affiliate and referral model.

Deploy on Railway: Go to railway.app and sign in with Login with GitHub. Click New Project then Deploy from GitHub repo. Select the aerlume-site repository. Railway detects this is a Node app and runs npm install then npm start automatically. Once deployed, go to Settings then Networking then Generate Domain to get a live public URL.

Optional custom domain: In the same Networking section, click Custom Domain and follow the instructions to point a domain you own at this deployment.

That is it, your site is live at a real working URL you can use for Payoneer, Travelpayouts, and anywhere else that asks for your website.
